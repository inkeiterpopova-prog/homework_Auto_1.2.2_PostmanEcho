# Автотесты API для PostmanEcho (Java + RestAssured)

Этот проект содержит набор автоматизированных тестов для проверки работы API на примере сервиса PostmanEcho. Проект создан в рамках обучения автоматизации тестирования на Java и демонстрирует навыки написания API-тестов и настройки CI/CD.

## 🎯 Цель проекта
Показать умение автоматизировать проверку API-эндпоинтов, валидировать структуру JSON-ответов и запускать тесты в непрерывной интеграции (CI).

## 🛠 Стек технологий
*   **Язык:** Java 11
*   **Фреймворк для тестов:** JUnit 5
*   **Библиотека для API:** RestAssured (включая json-schema-validator)
*   **Сборка:** Gradle
*   **CI/CD:** AppVeyor (настроен `appveyor.yml`)

## 🚀 Реализованные проверки
1.  **Позитивные тесты:** Проверка успешных ответов от сервера (статус-код 200, корректные данные).
2.  **Валидация JSON-схемы:** Проверка того, что структура ответа сервера соответствует ожидаемому контракту (с помощью `json-schema-validator`).
3.  **Параметризованные тесты:** Отправка разных наборов данных (headers, body) и проверка ответов.

## ⚙️ Как запустить
1. Убедитесь, что у вас установлена Java 11.
2. Склонируйте репозиторий.
3. Запустите тесты через терминал:
   * На Windows: `gradlew.bat test`
   * На Mac/Linux: `./gradlew test`
4. Отчет о тестировании будет доступен в папке `build/reports/tests/test/index.html`.

## 📊 Непрерывная интеграция (CI)
Проект интегрирован с **AppVeyor**. Файл `appveyor.yml` настроен на автоматический запуск сборки и тестов при каждом коммите в ветку `master`. Статус сборки отображается бейджем в самом верху этого файла.
